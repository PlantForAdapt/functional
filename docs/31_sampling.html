These sampling choices are made considering the inventory data of the 22/09/2026. This inventory contains 10386 individuals . For multistemed trees, we consider only the DBH of the bigger stem.

Unlike in 2025, the sampling is decided based on the botanical names (as identification as occurred since). There are 82 different species, with 141 unidentified tree. We add a botanical code using the two first letters of the genus and species. We also add a label using the botanical code and the tree ID, that will be used for sampling. NB: in the field, only the tree ID is displayed on the trees.

Objective

The functional traits will be used to:

  • characterize the ecological strategies of native tree species in order to explain species demography and response to climate (T1.1)

  • predict the outcome of species interactions on tree performances under drought (T2.1)

For the first objectives, we can focus in the planted species, but for the second, covering as much as possible the diversity of all species (planted or naturally regenerating) is important. We will therefore aim to sample all the planted species, and non-planted species representing the highest proportion of the stem number that we can achieve.

We will sample on minimum of 5 trees per species and per sites to account for intraspecific variability. However, to minimise the effect of ontogentic trait variations, we will standardise this by sampling on the biggest individuals (as a proxy for the tallest). TO DO: check for non-planted species that we are not sampling on too yound individuals.

The traits to measure are listed on this page, on 5 leaves per individual, except for TLP for which we take only two leaves and Gmin. For wood density, we take two wood cores per individual.

This second field campaign in Belterra aims at complementing the field campaign of 2025.

Species choice

Code 
abd <- inventory %>% 
  st_drop_geometry() %>% 
  filter(!is.na(botanical)) %>% 
  count(botanical, bota_code, planted, ppd_sen, native) %>% 
  arrange(desc(n)) %>% 
  mutate(prop = n/n_tree_tot,
         cum_prop = cumsum(prop),
         sampled_2025 = ifelse(botanical %in% unique(meas_2025$botanical),
                               TRUE,
                               FALSE))
