Correcting typos in vernacular codes and tree ID

See the issues here and here to understand the rationale for these corrections.

Code 
load_correct <- function(my_file, type ="tsv") {
  if (type == "tsv") {
    data <- read_tsv(my_file, show_col_types = FALSE)
  }
  if (type == "csv") {
    data <- read_csv(my_file, show_col_types = FALSE)
  }
  data <- data %>% mutate(
    vernacular = recode_values(vernacular,
                            "CUPUI" ~ "CUPIU",
                            default = vernacular),
    vernacular = recode_values(vernacular,
                            "PEQUI" ~ "PIQUI",
                            default = vernacular),
    tree = recode_values(tree,
                      8833 ~ 8883,
                      8383 ~ 8883,
                      6616 ~ 6617,
                      7734 ~ 7334,
                      default = tree),
    vernacular = if_else(tree %in% c(5685,6513), "FAVAO", vernacular)
  ) 
  if("comment" %in% colnames(data)) {
    data <-  data %>% select(-comment)
  }
  data
}

symdiff2 <- function(x, y, by) {
  x_sel <- select(x, all_of(by))
  y_sel <- select(y, all_of(by))
  diff <- union(setdiff(x_sel, y_sel), setdiff(y_sel, x_sel))
  if(nrow(diff) == 0) {
    print("There is a complete overlap between the two datasets")
  } else {
    print("The following tree/leaf are present in only one of the two datasets")
   diff %>% kable()
  }
}

Correcting for duplicated leaves

We remove all instances of the two duplicated COPAI 6910 leaves (leaves 1 and 2), for all traits. For leaf 1 of COPAI 6896, we take the mean of the tlp values for the two measurements of this leaf and attribute it to leave 1.
See here).

Code 
traits_cor <- traits_cor %>% 
  filter(!(tree == 6910 & leaf %in% c(1, 2))) %>% 
  mutate(tlp = if_else(
    (tree == 6896 & leaf == 1),

traits_cor %>% 
  select(sla, tlp, , tree, leaf, genus, species) %>% 
  mutate(genus_sp = paste(genus, species, sep="_")) %>% 
  na.omit() %>% 
  ggplot(aes(sla, tlp, col = as.character(tree))) +
  geom_smooth(aes(group = genus_sp), method = "lm", 
              col = "grey", alpha = .2) +
  geom_point() +
  theme_bw() +
  xlab(expression("SLA ["~cm^{2}~g^{-1}~"]")) +
  ylab(expression("TLP ["~MPa~"]")) +
  facet_wrap(~ genus_sp, scales = "free") +
  scale_color_discrete(guide = "none")

This figure is just made for exploration purposes, but we don’t expect the SLA-TLP relationship is not necessarly expected to hold intra-species. The higher LMA lower TLP relation holds good in inter-species relationships most of the time (it is often expected because high LMA is often linked to drought resistance strategies, and low TLP too, which is debatable). But this is not always the case (e.g. Isa’s work in Guyana).
