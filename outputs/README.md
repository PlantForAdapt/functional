# Outputs

All outputs of the analyses:

- Overall trait database : `trait_PlantForAdapt_vX.csv`

- Campaign specific trait database : `trait_PlantForAdapt_Site_year_vX.csv`

- version description in `NEWS`

## Metadata

- **site** (*character*): site name (Belterra, or....)

- **tree** (*numeric*): individual tree identifier, as in the original inventory of the site

- **leaf** (*numeric*): leaf identifier within the tree

- **genus** (*character*): genus

- **species** (*character*): species

- **verna_code** (*character*): vernacular code

- **vernacular** (*character*): full vernacular name

- **botanical** (*character*): botanical name as in the inventory (can contain authors)

- **family** (*character*): botanical family

- **campaign** (*character*): campaign name

- **la** (*numeric*): leaf area (LA) in $cm^2$

- **ldmc** (*numeric*): leaf dry matter content (LDMC) in $g.g^{-1}$

- **lt** (*numeric*): leaf thickness (LT) in $\mu m$

- **sla** (*numeric*): specific leaf area (SLA) in $cm^2.g^{-1}$

- **tlp** (*numeric*): leaf potential at turgor loss point (TLP) in $MPa$

- **comments** (*character*): comments related to data cleaning
